## Открытие

- Основная сцена: `имя-проекта.blend` (замени на настоящее имя файла).
- Версия Blender: укажи версию.
- Рендер-движок: укажи EEVEE или Cycles.
- Ресурсы: укажи, упакованы ли текстуры в сцену или находятся в `textures/`.

Открой файл сцены в Blender. Если настроены камера и свет, нажми F12 для рендера.

## Папки

| Путь | Содержимое |
|---|---|
| `*.blend` | Исходные сцены |
| `textures/` | Внешние текстуры |
| `screenshots/` | Выбранные изображения для галереи |
| `exports/` | Экспортированные модели, если нужны |
