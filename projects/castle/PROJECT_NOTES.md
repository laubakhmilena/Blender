# Технические заметки

## Сцена

- Версия Blender при подготовке: 5.3.0.
- Рендер: EEVEE.
- В сцене 234 объекта-меша с именами Cube…
- Базовый блок имеет размер 2 × 2 × 2 м.
- Для открытой копии проекта текстуры упакованы внутрь файла .blend.

## Выравнивание

Центры блоков установлены на ближайшие координаты сетки с шагом 2 м. Все размеры блоков приведены к 2 × 2 × 2 м. В исходной сцене один объект имел масштаб 0,9929; в подготовленной копии его масштаб нормализован.

Четыре ячейки содержат по два почти совпадающих объекта. Они оставлены в сцене, чтобы сохранить исходную геометрию без удаления объектов.

## Камера и свет

В подготовленной копии назначена камера для общего изометрического вида и добавлены источники света для EEVEE. Исходный файл на рабочем столе содержит выровненную геометрию; презентационная камера и дополнительный свет добавлены только в копию для публикации.
