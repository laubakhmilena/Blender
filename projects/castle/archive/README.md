# Архив исходной публикации

- `Blender-Castle.zip` — сохранённый исходный архив; он не пересобирался при упорядочивании репозитория.
- `SHA256SUMS-original.txt` — исходная ведомость контрольных сумм. Пути и суммы относятся к прежнему пакету, а не к текущей структуре репозитория.
- `gitattributes-original.txt` — исходный файл атрибутов, сохранённый для соответствия ведомости.

Для работы с текущей сценой открывай [04.blend](../04.blend). Архив может содержать прежние описания и структуру.
