# Замок из блоков в Blender

Небольшая 3D-сцена каменного замка в блочном стиле Minecraft. Модель собрана из кубов, с зубчатыми стенами, центральной башней и пиксельными каменными текстурами.

## Проект

- Основной файл сцены: [04.blend](04.blend)
- Blender: 5.3.0
- Рендер-движок: EEVEE
- Геометрия: 234 блочных объекта на сетке с шагом 2 м
- Текстуры упакованы внутрь файла .blend, отдельные файлы для открытия сцены не нужны

В поставляемой копии настроены камера и свет для быстрого рендера. Открой 04.blend в Blender и нажми F12, чтобы получить рендер.
